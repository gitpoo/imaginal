The experiment

A fictional bookbinding studio's planning session was parked on August 28, 2026 and resumed on October 31, 2026. The agent that picks it up is rebuilt from a trace of the old session and nothing else. 3 traces of the same session are compared: the full transcript (fidelity), a compaction-style summary (an imitation of the kind that ships in coding agents today), and a remap written for the next agent's goals, with a rent ledger per item. For each trace a fresh agent answers the same 8-item rubric, and each answer is scored against hand-written ground truth.

Item 4 is the trap. The trace carries a deadline that a sibling note, edited later, retracted, and what matters is whether the agent acts on it. The trap is also run under 5 salience conditions, which differ in whether and when the retraction is put in front of the agent.

Metrics: item scores from 0 to 1 (a pass is 0.5 or better), the trap state (caught, unaware or acted), survival % (the mean of the 8 item scores), trace tokens at session start, tokens injected, and survival per kilotoken.

What this run cannot show

  • All 45 runs on this page produced a verdict. A run that errors, submits nothing usable or states very low confidence would be shown grey and excluded, never scored by hand.
  • n is the number of seeds (3). Each seed is one synthetic world, so a cell holds at most 3 runs (backend api, model claude-sonnet-5-5). No confidence interval is quoted at this n: a cell is a count, not a rate estimate.
  • Scoring is keyword matching against hand-written ground truth, so it can miss a correct paraphrase and credit a lucky phrase. Every grid cell opens to the agent's own words next to its score: check the words before trusting a colour.
  • Ceiling: with no help (condition 0) the trap was avoided in 9 of 9 runs, so the other conditions had no headroom. This run cannot show that surfacing the retraction helps, only whether it hurts.
  • On the real 318-note corpus the audit's hit rate on hand-verified candidates was 41% (7 of 17 judgeable), Wilson 95% interval roughly 22 to 64%; no real note appears on this page.

Reproduce

From the repo root. The first and last commands make no network call, and the last rebuilds this page from the saved run. The middle one calls the API, needs a key, and writes a new file so the saved run is left alone.

python3 -I fixtures/synthetic/make_corpus.py --seed 1 --verify
python3 -I scripts/imaginal.py survive --seeds 1,2,3 --conditions 0,1,2,2d,2h --out runs/rerun.json
python3 -I scripts/imaginal.py demo --replay runs/demo.json
